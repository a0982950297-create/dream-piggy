# 夢想撲滿 V1 開發規格書

## 1. 專案定位

「夢想撲滿」是一個手機優先的個人存錢 Web App。

核心概念：

一隻豬，就是一個夢想。

使用者可以建立最多 5 隻夢想豬，每隻豬代表一個獨立目標。使用者只能存錢，不能取回。當金額達到 100% 後，才能解封，並進入成就館。

---

## 2. 技術限制

請只使用：

- HTML
- CSS
- JavaScript
- LocalStorage

不要使用：

- npm
- framework
- React
- Vue
- Firebase
- 資料庫
- 登入系統
- 測試框架

---

## 3. 檔案結構

請使用既有檔案：

- index.html
- style.css
- app.js
- data/pigs.json

---

## 4. 平台

手機優先設計。

畫面寬度以 390px 左右手機寬度為主要設計參考。

桌機可正常顯示，但不需要特別優化。

---

## 5. 視覺風格

風格名稱：

2D 偽潮玩風

視覺方向：

- Q 版可愛
- 圓潤
- 柔和色彩
- 有收藏玩具感
- 不要寫實 3D
- 不要太幼稚
- 要有作品感
- 奶白、粉橘、淡金、柔粉為主色
- 卡片使用圓角、柔光、陰影

整體氛圍：

溫暖、療癒、質感、可愛、像一個可以拿給家人看的作品。

---

## 6. 初始六種豬款

請在 data/pigs.json 建立以下六種豬款資料：

1. 夢想豬
2. 幸運豬
3. 愛心豬
4. 飛行豬
5. 音樂豬
6. 宅宅豬

每個豬款需包含：

- id
- name
- emoji
- themeColor
- description

若沒有圖片素材，請先用 emoji + CSS 插畫卡片方式呈現，不要引用不存在的圖片。

---

## 7. App 頁面

V1 只有兩個主要頁面：

1. 首頁
2. 成就館

底部導覽列只有：

- 首頁
- 成就館

不要加入設定頁。

右上角可以有一個「更多」按鈕，打開小選單：

- 匯出備份
- 匯入備份
- 清除資料

---

## 8. 首頁功能

首頁顯示：

- App 名稱：夢想撲滿
- 簡短標語：把想去的地方，慢慢存成現實。
- 目前夢想豬數量
- 全部夢想總存入金額
- 夢想豬輪播區
- 新增夢想按鈕

首頁最多顯示 5 隻夢想豬。

若沒有任何豬，顯示空狀態：

「還沒有夢想豬，建立第一個夢想吧。」

---

## 9. 夢想豬規則

最多只能建立 5 隻豬。

每隻豬資料包含：

- id
- name
- pigType
- targetAmount
- currentAmount
- createdAt
- unlockedAt
- status
- triggeredMilestones

status 可為：

- active
- completed

triggeredMilestones 用來記錄是否觸發過：

- created
- 25
- 50
- 75
- 100
- unlocked

---

## 10. 建立夢想豬

建立時只需要三個欄位：

1. 夢想名稱
2. 目標金額
3. 選擇豬款

不要加入：

- 截止日期
- 備註
- 存錢來源
- 分類
- 圖片上傳

建立完成後，新增到首頁輪播。

建立完成時觸發一次初始對話：

「從今天起，我會幫你守著這個夢想。」

---

## 11. 首頁輪播

五隻豬平等。

首頁用輪播方式呈現。

一次主要顯示一隻夢想豬。

要有：

- 左右切換
- 下方圓點指示
- 目前豬的名稱
- 豬款名稱
- 已存金額 / 目標金額
- 進度條
- 進度百分比
- 餵豬按鈕
- 若達 100%，顯示解封按鈕

---

## 12. 餵豬流程

點擊「餵豬」後，開啟彈窗。

彈窗文字：

「要餵多少給夢想呢？」

使用者輸入金額。

按鈕文字：

「投入夢想」

按下後：

- currentAmount 增加輸入金額
- 不能超過 targetAmount
- 儲存到 LocalStorage
- 播放簡單 CSS 動畫
- 更新進度條
- 判斷是否觸發里程碑

不要記錄：

- 備註
- 來源
- 支出
- 取回

此 App 只能存，不能取。

---

## 13. 動畫規格

V1 使用圖片 / CSS 動畫即可。

不要使用影片。

不要使用 Lottie。

不要使用 3D。

餵豬動畫：

- 金幣掉落
- 豬卡片輕微彈跳
- 卡片微微發光
- 金額短暫浮現

解封動畫：

- 金豬感
- 彩帶
- 星光
- 閃亮背景
- 顯示完成訊息

---

## 14. 里程碑對話

只有在重要進度時觸發對話。

不要每次餵豬都說話。

節點：

- 建立時
- 25%
- 50%
- 75%
- 100%
- 解封時

每個節點只觸發一次。

對話內容：

建立時：
「從今天起，我會幫你守著這個夢想。」

25%：
「你真的開始了。很多人有夢，但你開始存了。」

50%：
「我們已經走一半了。原來堅持，真的會累積成改變。」

75%：
「我已經能看見那個夢想了。再一下下，我們就到了。」

100%：
「你做到了。這不是運氣，是你一次一次堅持的結果。」

解封時：
「去吧。去把存下來的夢，活成回憶。」

---

## 15. 解封規則

只有 currentAmount >= targetAmount 才能解封。

解封後：

- status 改為 completed
- unlockedAt 記錄當下日期
- 從首頁 active 清單移除
- 加入成就館
- 釋出一個空位，可再新增新的夢想豬

解封不是領錢。

解封代表：

去追求夢想。

---

## 16. 成就館

成就館是極簡卡片牆。

顯示已完成夢想。

每張成就卡包含：

- 豬款
- 夢想名稱
- 完成日期
- 達標金額
- 花費天數

成就館上方顯示：

- 完成夢想數
- 累積完成金額

若沒有成就，顯示：

「完成的夢想，會收藏在這裡。」

不要加入：

- 徽章系統
- 等級系統
- 排行榜
- 社群分享

---

## 17. 備份功能

右上角更多選單提供：

### 匯出備份
將 LocalStorage 中的夢想豬與成就資料匯出成 JSON 檔案。

檔名建議：

dream-piggy-backup.json

### 匯入備份
使用 file input 匯入 JSON。

匯入後覆蓋目前資料。

匯入前顯示確認提醒。

### 清除資料
清除全部 LocalStorage。

必須跳出確認。

---

## 18. LocalStorage

使用 LocalStorage 儲存資料。

key 建議：

dreamPiggy.pigs

資料結構：

{
  "pigs": [],
  "achievements": []
}

---

## 19. 操作限制

- 不能建立第 6 隻 active 豬
- 金額只能輸入正整數
- 目標金額必須大於 0
- 餵豬金額不可為 0
- 已完成的豬不能再餵
- 已完成的豬不能回首頁

---

## 20. 禁止加入的功能

請不要加入：

- 登入
- 註冊
- 雲端同步
- 家庭共享
- 記帳功能
- 支出功能
- 取回金額功能
- 分類統計
- 報表
- 月曆
- 任務系統
- 提醒通知
- AI 對話
- 音效
- 影片動畫

---

## 21. 目標

完成後，這個 App 應該可以：

1. 新增最多 5 隻夢想豬
2. 每隻豬可輸入目標金額
3. 每隻豬可存錢
4. 進度會正確更新
5. 到達 25/50/75/100 時觸發一次對話
6. 100% 後可解封
7. 解封後進入成就館
8. 資料重新整理後仍存在
9. 可以匯出 / 匯入備份
10. 手機畫面好看、乾淨、有作品感

---

## 22. 開發注意事項

請以簡潔、可維護為主。

JavaScript 請拆成清楚函式，例如：

- loadData()
- saveData()
- renderHome()
- renderCarousel()
- createPig()
- feedPig()
- checkMilestones()
- unlockPig()
- renderAchievements()
- exportBackup()
- importBackup()

CSS 請包含：

- mobile-first layout
- card style
- carousel style
- modal style
- progress bar
- pig visual style
- coin animation
- glow animation
- unlock celebration animation

不要過度複雜化。
